# Project Instructions

## Project Overview
- This is a browser-based restaurant game centered on `index.html`.
- The main local assets live under `assets/`; project notes live under `DOC/`.
- Treat `DOC/AGENTS.md` as historical notes only unless its encoding is fixed.

## Working Rules
- For small, clear UI tweaks, make the minimal direct change and report briefly.
- For complex, multi-file, high-risk, or architectural work, share a plan before editing.
- If implementation diverges materially from the plan, report the change before continuing.

## Git
- After every completed code or project-file change, create a Git commit.
- Commit only files changed for the current request; do not stage unrelated user work.
- Use concise commit messages that describe the visible change.

## Code Quality
- Keep edits scoped to the requested behavior.
- Follow existing inline HTML/CSS/JS patterns unless there is a clear reason to change them.
- Do not leave temporary debug output.
- If a test, lint, build, or manual verification command is available and relevant, run it and report the result.
