# 開發防呆守則 (AGENTS.md)

## 1. 空間導航邏輯
- **雙重感應區**：所有空間跳轉必須同時更新 `drawNavigationArrows` (視覺) 與 `getDynamicNavZones` (判定)。
- **滯留時間**：全局統一為 `800ms` (Phase 6 更新)，提升流暢感。
- **洗手台限制**：
    - 進入：僅限從 KITCHEN 進入。
    - 離開：僅限回到 KITCHEN，且導航箭頭必須位於 **左側** 以避開訂單遮擋。

## 2. 交互區位規範
- **櫃檯 (COUNTER)**：
    - 接單方式：僅限 **微笑接單** (門檻 0.2)，不依賴手部偵測。
    - 提示文字：位於畫面左下角。
- **廚房 (KITCHEN)**：
    - 提示文字：固定於 **左上角** (x:20, y:40-80)，避開中心訂單區。
    - 盤子顯示：當 `cleanPlates === 0` 且盤子為空時，必須隱藏盤子底座。
- **用餐區 (DINING_ROOM)**：
    - 返回櫃檯：導航箭頭位於 **左側**。

## 3. 渲染與適配
- **Canvas 解析度**：固定 960x540。
- **UI 避讓**：頂部中央預留給 Overcooked 風格訂單卡片，寬度約 700px。
- **提示系統**：統一使用 `showTip(text)` 函數調用，提示位於螢幕中心。

## 4. 料理狀態機
- 出餐後必須呼叫狀態重置，清空 `plateHas...` 所有布林值，並扣除 `cleanPlates`。
- 接單後 `activeOrder` 為空時才可分配新任務。
