# 開發更新紀錄 (Changelog)

## [Phase 6.0] - 2026-05-12
### 核心交互重構 (Core Interaction Refactor)
- **微笑接單系統**：移除手勢滯留接單，改為純微笑觸發（偵測門檻 0.2），且不需偵測手部即可運作。
- **導航效能優化**：將區域跳轉的滯留時間從 1.5s 縮短至 0.8s，提升移動流暢度。
- **UI 空間避讓**：
    - 將廚房提示文字移回左上角。
    - 將洗手台至廚房的導航箭頭移至左側，避免被頂部訂單卡片遮擋。
- **經濟與平衡調整**：
    - 移除洗碗的金錢獎勵（改為純資源管理）。
    - 移除微笑對耐心的安撫效果。
    - 修正盤子庫存為 0 時的視覺自動隱藏與提示。

## [Phase 5.5] - 2026-05-11
### Added
- **自由配料順序**：重構廚房邏輯，玩家可先放配料再放麵，製程不再受限。
- **盤子庫存警示**：實作 `cleanPlates` 計數器，當數量為 0 時隱藏視覺並顯示「⚠️ 缺盤子」提示。
- **全螢幕座標適配**：修正全螢幕模式下 UI 判定偏移問題。
- **快速得分機制**：移除硬幣撿取，出餐成功直接加分。
- **難度調整**：大幅降低客人耐心衰減速率。

### Fixed
- **盤子殘留 Bug**：強制在出餐後重置所有盤子布林狀態（`plateHasNoodles` 等）。
- **洗手台存取限制**：修正導航邏輯，確保洗手台只能透過廚房進入。
- **UI 崩潰**：修復無訂單時 `activeOrder` 為空導致的渲染報錯。
