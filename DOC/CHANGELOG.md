# 開發更新紀錄 (Changelog)

## [Phase 7.0] - 2026-05-12
### 餐廳運作循環與特寫清理 (Restaurant Lifecycle & Focused Cleaning)
- 實作「特寫清理頁面 (TABLE_CLEANING)」，將打掃動作從用餐區獨立出來。
- 引入 Matter.js 物理垃圾撥除與進度條擦拭機制。
- 移除所有清理獎勵，確保經濟系統唯一來源為成功出餐 ($25)。
- 修復 `renderGame` 分支結構，移除舊版掉落硬幣邏輯。
- 用餐區顯示「停留進入清理」引導，提升引導性。

## [Phase 7.1] - 2026-05-12
### 雙手操作與數值平衡 (Dual-Hand Support & Balancing)
- **雙手全功能支援**：重構 `handleCookingLogic` 與 `handleHandLogic`，實現左右手同步操作（抓取、出餐、清理）。
- **耐心值平衡**：調慢客人的耐心下降速度（點餐速度調慢 50%，等餐速度調慢 40%），降低前期壓力。
- **垃圾條件生成**：桌面上是否出現「飲料杯」改為動態判定（根據客人是否有飲料訂單）。
- **視覺強化**：將清理畫面的餐具顏色改為深木色，提升辨識度。
- **穩定性修復**：修正雙手邏輯重構後的語法衝突與變數作用域。

## [Phase 6.0] - 2026-05-12
### 核心交互重構 (Core Interaction Refactor)
- **微笑接單系統**：移除手勢滯留接單，改為純微笑觸發（偵測門檻 0.2），且不需偵測手部即可運作。
- **導航效能優化**：將區域跳轉的滯留時間從 1.5s 縮短至 0.8s，提升移動流暢度。
- **UI 空間避讓**：
    - 將廚房提示文字移回左上角。
    - 將洗手台至廚房的導航箭頭移至左側，避免被頂部訂單卡片遮擋。
- **經濟與平衡調整**：
    - 移除洗碗的金錢獎勵（改為純資源管理）。
    - 移除微笑對耐心的安撫效果。
    - 修正盤子庫存為 0 時的視覺自動隱藏與提示。

## [Phase 5.5] - 2026-05-11
### Added
- **自由配料順序**：重構廚房邏輯，玩家可先放配料再放麵，製程不再受限。
- **盤子庫存警示**：實作 `cleanPlates` 計數器，當數量為 0 時隱藏視覺並顯示「⚠️ 缺盤子」提示。
