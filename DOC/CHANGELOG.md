# 開發更新紀錄 (Changelog)

## [Phase 5.5] - 2026-05-11
### Added
- **自由配料順序**：重構廚房邏輯，玩家可先放配料再放麵，製程不再受限。
- **全螢幕支持**：遊戲畫面現在支援全螢幕自動縮放，並保持 16:9 比例。
- **導航層級重構**：將洗手台移動至廚房區域內，優化店內動線。
- **防呆提示**：洗手台加入「盤子已滿」提示，出餐後自動隱藏桌面盤子。

### Fixed
- **語法錯誤修正**：修復了 `renderGame` 中導致遊戲無法啟動的 `Unexpected token 'else'`。
- **座標偏移修正**：修復全螢幕下 HTML 按鈕無法感應的座標轉換 Bug。
- **洗碗進度保留**：修復切換空間會導致洗碗進度重置的問題。
- **感應穩定性**：大幅擴大洗盤子感應區，並加入位移跳變過濾，操作更平滑。

## [2026-05-11] Phase 5: 食材擴充與客流優化 (Cement & Flow Polish)

### 新增 (Added)
- **新食材「混泥土 (Cement)」**：廚房新增混泥土放置區，並增加「混泥土麵」、「混泥土香菜麵」等新訂單類型。
- **用餐區入座機制**：接單後客人不再待在櫃檯，而是自動移動至「用餐區 (`DINING_ROOM`)」入座等餐，櫃檯則由下一位排隊者補上。
- **水平導航佈局**：重構區域切換邏輯為「廚房在左、櫃檯在中、用餐區在右、洗手台在下」，更符合空間直覺。
- **盤子資源管理**：實作盤子消耗與洗碗機制，出餐需消耗乾淨盤子，沒盤子時需前往洗手台洗碗。

### 變更 (Changed)
- **料理流程升級**：從 6 步增加為 7 步，新增「加入混泥土」階段。
- **平衡調整**：
  - 大幅調慢等餐時的耐心扣除速度 (`0.035` -> `0.02`)。
  - 顯著提高攪拌速度，將累積路徑閾值從 `3000` 降至 `1200`。
- **UI 強化**：頂部訂單卡片改為類似 Overcooked 的圖示與進度條組合，並顯示具體餐點名稱。

### 修復 (Fixed)
- **視覺修復**：修正攪拌進度環與實際進度不匹配的問題（同步至 1200 閾值）。
- **視覺修復**：修正鍋子在盛盤後仍顯示麵糰的殘留 bug。
