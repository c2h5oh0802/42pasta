# 開發更新紀錄 (Changelog)

## [Phase 7.0] - 2026-05-12
### 桌面整理與用餐循環 (Table Cleaning & Eating Cycle)
- **桌位狀態機**：實作 `FREE`, `OCCUPIED`, `EATING`, `DIRTY` 四種桌位狀態。
- **接單阻斷機制**：若無 `FREE` 桌位（全滿或全髒），則無法接單，並提示玩家先清理桌面。
- **用餐計時器**：出餐後客人進入 5 秒用餐期（顯示藍色進度條），結束後桌位自動轉為 `DIRTY`。
- **整理任務系統**：
    - 在「用餐區」對髒桌子進行持續擦拭（顯示黃色進度條）以恢復空位。
    - 移除所有清理類動作的金錢獎勵（包括擦桌子與撥除垃圾）。
- **視覺強化**：用餐區現在能精準顯示不同狀態下的客人與桌面污漬。

## [Phase 6.0] - 2026-05-12
### 核心交互重構 (Core Interaction Refactor)
- **微笑接單系統**：移除手勢滯留接單，改為純微笑觸發（偵測門檻 0.2），且不需偵測手部即可運作。
- **導航效能優化**：將區域跳轉的滯留時間從 1.5s 縮短至 0.8s，提升移動流暢度。
- **UI 空間避讓**：
    - 將廚房提示文字移回左上角。
    - 將洗手台至廚房的導航箭頭移至左側，避免被頂部訂單卡片遮擋。
- **經濟與平衡調整**：
    - 移除洗碗的金錢獎勵（改為純資源管理）。
    - 移除微笑對耐心的安撫效果。
    - 修正盤子庫存為 0 時的視覺自動隱藏與提示。

## [Phase 5.5] - 2026-05-11
### Added
- **自由配料順序**：重構廚房邏輯，玩家可先放配料再放麵，製程不再受限。
- **盤子庫存警示**：實作 `cleanPlates` 計數器，當數量為 0 時隱藏視覺並顯示「⚠️ 缺盤子」提示。
