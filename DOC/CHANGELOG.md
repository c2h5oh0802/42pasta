# 開發更新紀錄 (Changelog)

## [Phase 6.0] - 2026-05-12
### 核心交互重構與穩定化 (Interaction Refactor & Stabilization)
- **微笑接單系統**：實現純臉部感應接單，門檻優化至 0.2，並新增視覺感應指示器。
- **偵測逻辑解耦**：修正「必須伸手才能微笑」的 Bug，確保臉部與手勢處理完全獨立。
- **導航效能翻倍**：跳轉時間從 1.5s 縮短至 0.8s，大幅提升遊玩節奏。
- **UI 佈局最終校準**：
    - 修復洗手台回廚房的箭頭被訂單卡片遮擋的問題。
    - 料理提示文字回歸左上角，優化 Overcooked 風格訂單顯示空間。
- **遊戲平衡調整**：
    - 移除洗碗金錢獎勵，強化資源管理性質。
    - 移除微笑恢復耐心的機制，簡化交互邏輯。
- **結算系統優化**：進入結算畫面時自動清理所有頂部 UI 元素，確保視覺焦點。

## [Phase 5.5] - 2026-05-11
### 功能更新與 Bug 修復
- **自由配料流程**：解除硬性料理順序，玩家可自由組合配料。
- **盤子庫存系統**：實作 `cleanPlates` 管理，盤子用罄時給予視覺警告並阻斷動作。
- **全螢幕座標修復**：修正鏡頭偏移與 UI 判定偏差。
- **防崩潰機制**：加入大量空值檢查，防止無訂單時的渲染報錯。
- **空間跳轉規範**：確立「洗手台出口僅限廚房」的拓撲規則。
